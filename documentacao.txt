## 4. LÓGICA DE CÁLCULO DE JUROS (O Coração do Sistema)


```
╔══════════════════════════════════════════════════════╗
║  JUROS SIMPLES DIÁRIOS SOBRE SALDO REMANESCENTE     ║
╚══════════════════════════════════════════════════════╝


Exemplo prático:
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━


Empréstimo: R$ 1.000,00
Taxa diária: 0,5% (0.005)
Data início: 01/Jan


📅 Dia 01-10 (10 dias, sem pagamento):
   Saldo = 1000 + (1000 × 0.005 × 10) = R$ 1.050,00


📅 Dia 10: Cliente paga R$ 300,00
   Novo saldo = 1050 - 300 = R$ 750,00


📅 Dia 10-20 (mais 10 dias):
   Saldo = 750 + (750 × 0.005 × 10) = R$ 787,50


📅 Se quitar no dia 20: paga R$ 787,50
📅 Se quitar no dia 25: 
   Saldo = 750 + (750 × 0.005 × 15) = R$ 806,25
```


### Função de Cálculo (pseudocódigo):


```javascript
function calcularSaldo(emprestimo, pagamentos, dataAlvo) {
    let saldo = emprestimo.principalAmount;
    let ultimaData = emprestimo.startDate;
    
    // Ordena pagamentos por data
    pagamentos.sort((a, b) => a.date - b.date);
    
    // Percorre cada pagamento
    for (let pgto of pagamentos) {
        if (pgto.date > dataAlvo) break;
        
        // Calcula juros do período anterior
        let dias = diasEntre(ultimaData, pgto.date);
        saldo = saldo + (saldo * emprestimo.dailyInterestRate * dias);
        
        // Subtrai o pagamento
        saldo = saldo - pgto.amount;
        ultimaData = pgto.date;
    }
    
    // Calcula juros do último evento até a data alvo
    let diasRestantes = diasEntre(ultimaData, dataAlvo);
    saldo = saldo + (saldo * emprestimo.dailyInterestRate * diasRestantes);
    
    return Math.max(saldo, 0); // Nunca negativo
}
```

## 9. REGRAS DE SEGURANÇA (Firestore)


```javascript
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    
    // Admins podem tudo
    function isAdmin() {
      return get(/databases/$(database)/documents/users/$(request.auth.uid)).data.role == 'admin';
    }
    
    // Users
    match /users/{userId} {
      allow read: if request.auth.uid == userId || isAdmin();
      allow write: if isAdmin();
    }
    
    // Loans
    match /loans/{loanId} {
      allow read: if resource.data.clientId == request.auth.uid || isAdmin();
      allow write: if isAdmin();
      
      // Payments
      match /payments/{paymentId} {
        allow read: if get(/databases/$(database)/documents/loans/$(loanId)).data.clientId == request.auth.uid || isAdmin();
        allow write: if isAdmin();
      }
    }
  }
}
```

## 10. FLUXO DE OPERAÇÃO


```
CRIAÇÃO DO EMPRÉSTIMO:
Admin cadastra cliente → Admin cria empréstimo → Sistema registra


VIDA DO EMPRÉSTIMO:
Juros acumulam automaticamente (cálculo em tempo real, sem cron job!)
↓
Cliente acessa → Vê saldo atualizado → Simula datas
↓
Cliente paga → Admin registra pagamento → Saldo recalculado
↓
Saldo = 0 → Status muda para "paid" ✅


⚡ PONTO CHAVE: Não precisamos de Cloud Functions!
   Os juros são calculados NO MOMENTO DA CONSULTA,
   não armazenados. Isso simplifica TUDO.
```
